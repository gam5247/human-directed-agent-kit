# 작은 연습: 검사 배치의 불량 현황

`inspection.csv`는 직접 만든 가상 자료다. 실제 회사·시험 자료가 아니다.

운영 담당자가 검사 배치별 현황을 보고 다음 검토 대상을 정하려 한다. CSV를 읽고 데이터 문제를 확인해, 요약과 검토 순서를 만들 방법을 제안하라. 사용자는 개발자가 아니며 결과의 의미와 중요한 선택을 이해하고 싶어 한다.

미리 특정 모델·라이브러리를 정하지 않는다. 관측과 정책 선택을 구분하고, 자료만으로 결정할 수 없는 처리 기준은 추천과 함께 질문한다. 답변 없이 정책을 확정하거나 최종 순위를 만들어 내지 않는다. 기다리는 동안 할 수 있는 데이터 점검은 계속할 수 있다.

## 실제 사용 순서

1. 빈 연습 폴더에 이 CSV를 복사하고 지침·스킬을 설치한다.
2. Codex에서 위 요청을 준다. 직접 계산 가능한 사실과 사람에게 돌려준 결정을 읽는다.
3. 사용자가 데이터의 의미와 정책을 결정하고 답한다. 실제 지식이 없으면 가상 실습용 가정임을 명시한다.
4. 합의한 정책대로 요약을 구현·실행하게 한다. 실제 포함 행과 분모를 대조한다.
5. 결과를 보지 않고 핵심 선택의 이유와 실패 조건을 자기 말로 설명한다.

## 관측을 시작하는 명령

```sh
python practice/profile.py practice/inspection.csv
```

이 명령은 행 수·누락·반복 배치·상태만 표시하며, 중복 제거·결측 대체·업무상 순위를 결정하지 않는다. 프로파일 실행은 지침을 모델이 따른다는 증거나 사용자의 숙련 증명이 아니다.

추가 연습: 이미 결정한 정책의 반복 구현은 불필요한 검색·승인 없이 끝내는지, 새 데이터 때문에 정책이 흔들릴 때 해당 부분만 다시 질문하는지 확인한다.
